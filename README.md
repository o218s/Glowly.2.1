Glowly — demonstração de loja de skincare

Projeto front-end em HTML, CSS e JavaScript.

Estrutura

• index.html — estrutura e conteúdo da página
• css/style.css — estilos e layout responsivo
• js/script.js — interações e funcionalidades

Como executar

1. Descarrega ou clona este repositório.
2. Abre index.html no navegador.
3. Para publicar gratuitamente, ativa GitHub Pages nas definições do repositório (Settings → Pages) e escolhe a branch principal e a pasta / (root).

Notas importantes

• O carrinho, perfil, favoritos, diário, avaliações, encomendas e rastreio usam armazenamento local do navegador (localStorage).
• O checkout, métodos de pagamento, portes e rastreio são apenas demonstrações. Não processam pagamentos nem criam encomendas reais.
• Algumas imagens e tipos de letra são carregados de serviços externos; para os ver, é necessária ligação à Internet. As imagens incorporadas em data: já fazem parte do HTML.
• Este projeto é uma demonstração front-end e não inclui servidor, base de dados, autenticação ou integração de pagamentos.
